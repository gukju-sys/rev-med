These local WebP assets are illustration and icon crops from the three desktop PNG references supplied by the user (UNICELL, PRP UNI, CELL MOVER). They are used alongside semantic HTML text and links; the page layouts are implemented in css/design.css.

The PRP hero includes the reference artwork's product logo and image caption. The kit illustration includes its two product labels. Other page headings, descriptions, navigation, calls to action, product selection, and condition links are HTML.

The original product WebP files in assets/ are reused for the interactive product collection. Source Figma layers and original illustration exports were unavailable, so these reference crops can be replaced with original exports later without changing the layouts.

The updated home page uses the *-v2 assets, ribbon assets, and products-orbit.webp extracted from raster images embedded in the supplied UNICELL SVG. Its scoped layout overrides are in css/home-reference.css.
